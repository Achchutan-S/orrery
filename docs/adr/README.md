# Architecture Decision Records

One file per decision. The blueprint (`docs/blueprint.md` §6) holds the full context; these files record the decision, its status and what implementation learned.

To change a decision, add a new numbered ADR that states which one it supersedes and why, and set the old one's status to `superseded by ADR-0NN`. Never rewrite an accepted decision in place.
