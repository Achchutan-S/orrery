# Direction registry

One file per experience: its brief, the directions considered, and every design review, including rejections. This is the platform's creative memory ([creative process](../creative-process.md)). The repository is public, so every record is public.

**Rules**

- Start a record by copying [`_template.md`](_template.md) to `<experience-id>.md`.
- Never delete a rejected direction or a rejected review. They are the most useful part.
- A record is not imported by code and not referenced by the catalog (blueprint D9). An experience's README links to its record.
- Only the owner writes "approved". Only what a person looked at is recorded as reviewed.
